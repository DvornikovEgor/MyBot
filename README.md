# 🎙️ MyBot — Голосовой ИИ

Приложение на Python, которое **умеет делать голоса**: превращает любой текст
в живую речь с помощью нейросетей. Есть красивый веб-интерфейс и командная
строка.

## Возможности

- **Офлайн-движок на нейросети Silero v4** — 6 русских голосов
  (Айдар, Бая, Ксения, Ксения‑2, Евгений, «Случайный»). Модель ~40 МБ,
  после скачивания работает полностью без интернета.
- **Облачный движок Edge TTS** — сотни нейроголосов на десятках языков
  (нужен интернет, ключи не нужны).
- Регулировка **скорости**, выбор частоты (24/48 кГц), ударения и буква «ё».
- **История озвучек** с прослушиванием и скачиванием файлов.
- Автоматическое определение доступных движков: приложение не падает,
  если чего-то нет, а подсказывает, что доустановить.

## Быстрый старт

```bash
# 1. Зависимости (лучше в виртуальном окружении)
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
# машина без NVIDIA? легче поставить CPU-версию:
#   pip install torch --index-url https://download.pytorch.org/whl/cpu

# 2. Скачать нейромодель (однократно, ~40 МБ)
python app.py download-models

# 3. Запустить веб-интерфейс
python app.py serve
# → откройте http://127.0.0.1:8000
```

## Командная строка

```bash
python app.py voices                          # список доступных голосов
python app.py say "Привет, мир!"              # озвучить голосом по умолчанию
python app.py say "Текст" --voice silero/aidar --speed 1.2 --out hello.wav
python app.py say "Hello!" --voice edge/en-US-AriaNeural   # облачный голос
python app.py serve --host 0.0.0.0 --port 8000             # веб-сервер
python app.py download-models                 # скачать модель вручную
```

## Как это устроено

```
MyBot/
├── app.py                  # сервер (Flask) + CLI
├── voiceai/
│   ├── registry.py         # автоопределение доступных движков
│   ├── download_models.py  # загрузчик нейромодели (несколько зеркал)
│   ├── audio.py            # WAV-утилиты
│   └── engines/
│       ├── base.py         # интерфейс движка (голоса, синтез)
│       ├── silero.py       # офлайн-нейросеть Silero v4 (русские голоса)
│       └── edge.py         # облачный Edge TTS (нужен интернет)
├── webui/index.html        # одностраничный интерфейс без сборки
├── models/                 # сюда кладётся файл модели v4_ru.pt
└── outputs/                # сюда сохраняются озвучки
```

Добавить свой движок просто: унаследуйте `Engine` из
`voiceai/engines/base.py`, реализуйте `voices()` и `synthesize()`,
и подключите его в `voiceai/registry.py`.

## Модель и лицензии

- Файл `models/v4_ru.pt` скачивается с официального сервера
  [Silero](https://github.com/snakers4/silero-models) (или с запасного
  зеркала на GitHub) и **не входит в репозиторий**.
- Код приложения распространяется свободно. Модель Silero предоставляется
  на условиях её авторов: бесплатна для некоммерческого использования
  (лицензия модели — см. репозиторий Silero).

## Частые вопросы

**Приложение пишет «нет модели».** Выполните `python app.py download-models`
или нажмите кнопку «Скачать модель» прямо в веб-интерфейсе.

**Нет интернета.** Офлайн-движок продолжит работать, облачный автоматически
отключится — статус движков виден в шапке интерфейса.

**Хочу другие языки/голоса.** Подключите интернет — и в списке появятся все
облачные голоса (английский, немецкий, французский и десятки других).
