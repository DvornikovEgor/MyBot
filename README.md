# MyBot 🎵 + ⛏

Два проекта в одном репозитории: демо «ИИ учится играть в Майнкрафт» и генератор музыки.

---

## 1. ИИ играет в Майнкрафт (обучение с подкреплением) ⛏

Демо, в котором агент методом **Q-learning** учится добывать ресурсы в упрощённом
майнкрафт-подобном мире — прямо в браузере, без внешних сервисов и моделей.

**Откройте `minecraft.html`** (ссылка есть в шапке главной страницы).

### Возможности

- Агент видит состояние мира (куда идти до ближайшего блока, есть ли блок перед ним)
  и выбирает одно из 4 действий: **← → ⛏ ·**
- **Награды**: +10 дерево, +15 уголь, +50 полная зачистка, ±1 «компас» (к цели / от цели), −2 удар в пустоту
- Обучение по формуле Беллмана: `Q(s,a) ← Q(s,a) + α·[r + γ·max Q(s',a') − Q(s,a)]`
- ε-greedy исследование: сначала блуждает наугад, по мере затухания ε — действует оптимально
- Обучение идёт на **скрытой копии мира**, а на экране лучшая стратегия играет «вживую» —
  видно, как меняется поведение и растёт награда
- **График вознаграждения**, **тепловая карта выученной политики**, ночной цикл, экспорт истории в `.csv`
- Мир детерминирован сидом (в URL) — по ссылке воспроизводится тот же мир

### Как это устроено

| Файл | Роль |
|------|------|
| `js/mc/world.js` | сеточный мир: ландшафт, деревья, уголь, шаги, награды |
| `js/mc/agent.js` | Q-таблица, ε-greedy выбор, обновление Беллмана |
| `js/mc/renderer.js` | отрисовка мира на canvas (день/ночь, вспышки добычи) |
| `js/mc/main.js` | цикл обучения, метрики, графики, управление |
| `minecraft.html`, `css/mc.css` | страница и оформление демо |

## 2. Генератор музыки 🎵

Веб-генератор музыки: **сочиняет и синтезирует треки прямо в браузере**, без внешних сервисов и моделей.
Алгоритмическая композиция (гармония, мелодия, бас, арпеджио, барабаны) + синтез через Web Audio API + экспорт в WAV.

### Возможности

- **6 стилей**: Lo-fi, Synthwave, Эмбиент, Техно, Chiptune, Классика
- **5 настроений**: радостное, грустное, мечтательное, тёмное, эпичное — влияют на лад, темп и энергию
- Выбор тональности, темпа (или авто под стиль) и длины трека (~30–120 с)
- **Воспроизводимая генерация**: сид в URL — одна и та же музыка по одной и той же ссылке
- Фортепианный ролл с аккордами и структурой трека, живой спектр-визуализатор
- Циклическое воспроизведение, перемотка, регулятор громкости
- **Экспорт в WAV** (16-bit PCM) — ровно то, что вы слышите

### Как музыка сочиняется

1. **Теория** (`js/theory.js`): лады, диатонические аккорды, ведение голосов, пресеты стилей и ритм-паттернов.
2. **Композитор** (`js/composer.js`): выбирает гармонический прогресс (например, i–VI–III–VII для синтвейва),
   строит структуру (интро → A → B → аутро), пишет мелодию фразами с переиспользованием мотива,
   раскладывает бас, подложку, арпеджио и ударные с гуманизацией тайминга и свингом.
3. **Движок** (`js/engine.js`): озвучивает события осцилляторами и шумом — FM-электропиано, пады, кислотный бас,
   аналоговые и чиптюн-барабаны, реверберация, дилей и sidechain-«насос»; для Lo-fi добавляет виниловый шум.
4. Всё рендерится офлайн (`OfflineAudioContext`) одним буфром — поэтому экспорт в WAV идентичен прослушиванию.

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Space` | пуск / пауза |
| `G`     | сгенерировать новый трек |
| `Enter` в поле сида | генерация |

## Запуск

```bash
python3 server.py          # http://localhost:8000
```

Любой статический сервер тоже подойдёт, например `python3 -m http.server 8000`.

## Структура

```
index.html           — генератор музыки (интерфейс)
minecraft.html       — демо «ИИ играет в Майнкрафт»
css/style.css        — оформление музыки
css/mc.css           — оформление демо RL
js/theory.js         — музыкальная теория и пресеты
js/composer.js       — алгоритмический композитор
js/engine.js         — синтез (Web Audio API)
js/wav.js            — кодировщик WAV
js/app.js            — UI, плеер, ролл и визуализатор
js/mc/world.js       — мир для ИИ
js/mc/agent.js       — Q-learning агент
js/mc/renderer.js    — отрисовка мира
js/mc/main.js        — обучение и метрики
server.py            — локальный статический сервер
```
