# MyBot 🤖

**Локальный ИИ-собеседник на чистом Python — без API, без интернета, без сторонних библиотек.**

Бот живёт прямо в терминале, отвечает на вопросы, считает выражения, помнит ваше
имя и — главное — **умеет учиться**: если он чего-то не знает, просто напишите
ему ответ, и он запомнит его навсегда в локальном JSON-файле.

## Возможности

- 💬 Диалог: приветствия, прощания, шутки, «как дела», знакомство.
- 🧠 База знаний (20 фактов встроено сразу) + нечёткий поиск
  (понимает даже фразы с опечатками — спасибо `difflib`).
- 📚 Обучение на ходу: `научи меня` происходит автоматически — бот сам
  спрашивает ответ, когда не знает.
- 🧮 Безопасный калькулятор на основе разбора AST (без `eval`, без
  выполнения кода): «сколько будет 2+2*2?», поддерживаются `^` и запятые.
- 🕒 Дата и время, 🪙 монетка, 🎲 кубик, ✂️ камень-ножницы-бумага.
- ✍️ Генератор текста на цепях Маркова — бот сочиняет фразы из того,
  что выучил (`/болтать`).
- 🛡️ Бот написан так, чтобы не падать: любой ввод обрабатывается,
  битые файлы данных автоматически убираются в `.bak`.

## Запуск

Ничего устанавливать не нужно — только стандартная библиотека Python 3.8+:

```bash
python3 main.py
```

## Пример разговора

```
Вы> привет!
Бот> Привет! 👋 Я локальный ИИ на Python, работаю без всяких API.
Вы> сколько будет (2+3)*4?
Бот> Считаю: 20
Вы> что такое кварк?
Бот> Хм, этого я пока не знаю. Но меня можно научить: напишите
     следующим сообщением свой вариант ответа — или слово «пропустить».
Вы> Это элементарная частица.
Бот> Запомнил! Теперь на «что такое кварк» я буду отвечать именно так.
Вы> кто написал Евгений Онегин?
Бот> «Евгения Онегина» написал Александр Сергеевич Пушкин…
```

## Команды

| Команда                | Что делает                          |
|------------------------|-------------------------------------|
| `/помощь`              | Справка                             |
| `/учить вопрос \| ответ` | Запомнить новую пару вопрос-ответ |
| `/забыть вопрос`       | Удалить запись из памяти            |
| `/база`                | Показать базу знаний                |
| `/болтать`             | Сочинить фразу цепями Маркова       |
| `/профиль`             | Что бот помнит о вас                |
| `/выход`               | Выйти                               |

## Тесты

Проверить, что всё работает без ошибок:

```bash
python3 -m unittest discover tests -v
```

Набор включает проверку калькулятора (включая попытки инъекций), поиск по
базе знаний, обучение, память имени, генератор Маркова и фаззинг из 300+
случайных строк — бот обязан ответить на каждую и не упасть.

## Структура проекта

```
main.py          — интерактивный чат
bot/
  brain.py       — «мозг»: диалог, база знаний, обучение, команды
  skills.py      — калькулятор (безопасный), дата/время, рандом
  markov.py      — генератор текста на цепях Маркова
tests/
  test_bot.py    — тесты (стандартный unittest)
data/            — создаётся автоматически: выученные знания и профиль
```
