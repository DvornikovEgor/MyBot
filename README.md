# 🎙️ MyBot — Голосовой ИИ

Приложение на Python, которое **умеет делать голоса**:

1. **Озвучивает любой текст** нейросетевыми голосами (офлайн и в облаке).
2. **Клонирует ваш голос**: записываете 10–30 секунд речи — и ИИ озвучит
   любой текст вашим голосом на русском и ещё 16 языках.

Есть веб-интерфейс (с записью с микрофона) и командная строка.

## Возможности

| Режим | Движок | Что нужно |
|---|---|---|
| 🎙 Озвучка текста (офлайн) | **Silero v4** — 6 русских голосов | модель ~40 МБ |
| ☁ Озвучка текста (облако) | **Edge TTS** — сотни голосов, десятки языков | интернет |
| 🎭 Клонирование голоса | **XTTS v2** — ваш голос из записи, 17 языков | модель ~1.9 ГБ |

- Регулировка скорости, частоты, ударений и буквы «ё».
- Запись образца **прямо с микрофона** в браузере (или загрузка файла —
  конвертация в WAV автоматическая).
- Библиотека «моих голосов», история озвучек, скачивание файлов.
- Движки определяются автоматически: приложение не падает, если чего-то
  нет, а подсказывает, что доустановить/скачать.

## Быстрый старт

```bash
# 1. Зависимости (лучше в виртуальном окружении)
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
# машина без NVIDIA? легче поставить CPU-версию:
#   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu

# 2. Скачать модели (однократно)
python app.py download-models          # озвучка: ~40 МБ
python app.py download-clone-model     # клонирование: ~1.9 ГБ (нужен доступ к huggingface.co)
# (обе модели можно скачать и кнопками прямо в веб-интерфейсе)

# 3. Запустить веб-интерфейс
python app.py serve
# → откройте http://127.0.0.1:8000
```

## Клонирование голоса за 3 шага

1. Вкладка **«Клонирование голоса»** → «Записать с микрофона» (10–30 секунд
   спокойной речи без музыки) или перетащите аудиофайл.
2. Сохраните голос под именем, затем выберите его в списке «Мои голоса».
3. Введите текст, выберите язык и нажмите **«Озвучить моим голосом»**.

Совет: чем чище запись, тем точнее копия. Синтез клонированного голоса
занимает от нескольких секунд до минуты (зависит от компьютера).

## Командная строка

```bash
python app.py voices                              # список доступных голосов
python app.py say "Привет, мир!"                  # озвучить голосом по умолчанию
python app.py say "Текст" --voice silero/aidar --speed 1.2 --out hello.wav
python app.py say "Hello!" --voice edge/en-US-AriaNeural   # облачный голос
python app.py clone "Текст" --voice moy-golos --lang ru    # клонированным голосом
python app.py serve --host 0.0.0.0 --port 8000             # веб-сервер
python app.py download-models                              # модель озвучки
python app.py download-clone-model                         # модель клонирования
```

## Как это устроено

```
MyBot/
├── app.py                  # сервер (Flask) + CLI
├── voiceai/
│   ├── registry.py         # автоопределение доступных движков
│   ├── download_models.py        # загрузчик модели Silero (~40 МБ)
│   ├── download_clone_model.py   # загрузчик модели XTTS v2 (~1.9 ГБ)
│   ├── audio.py            # WAV-утилиты
│   └── engines/
│       ├── base.py         # интерфейс движка (голоса, синтез)
│       ├── silero.py       # офлайн-нейросеть Silero v4 (русские голоса)
│       ├── edge.py         # облачный Edge TTS (нужен интернет)
│       └── xtts.py         # клонирование голоса (XTTS v2) + библиотека образцов
├── webui/index.html        # одностраничный интерфейс без сборки
├── models/                 # сюда скачиваются нейромодели
├── voice_samples/          # сохранённые образцы вашего голоса
└── outputs/                # готовые озвучки
```

Добавить свой движок просто: унаследуйте `Engine` из
`voiceai/engines/base.py`, реализуйте `voices()` и `synthesize()`,
и подключите его в `voiceai/registry.py`.

## Модели и лицензии

- **Silero v4** (`models/v4_ru.pt`, ~40 МБ) — скачивается с официального
  сервера Silero или с запасного зеркала. Бесплатна для некоммерческого
  использования (см. лицензию проекта [Silero](https://github.com/snakers4/silero-models)).
- **XTTS v2** (`models/xtts-v2/`, ~1.9 ГБ) — скачивается с
  [huggingface.co/coqui/XTTS-v2](https://huggingface.co/coqui/XTTS-v2).
  Лицензия модели — Coqui Public Model License: некоммерческое использование.
- Модели в репозиторий не входят — только загрузчики.

## Частые вопросы

**«Нет модели» / кнопка скачивания.** Нажмите кнопку в интерфейсе или
выполните команду загрузки (см. выше). Для модели клонирования нужен
доступ к huggingface.co.

**Нет интернета.** Офлайн-озвучка продолжит работать, облачный движок и
скачивание моделей отключатся — статусы видны в шапке интерфейса.

**Другие языки.** Озвучка: подключите интернет — появятся все облачные
голоса. Клонирование: выбирайте язык из списка (17 языков у XTTS).

**Сколько ресурсов нужно?** Озвучка — лёгкая, работает почти везде.
Клонирование потребует ~3–4 ГБ оперативной памяти при генерации и
несколько минут на первую загрузку модели.
