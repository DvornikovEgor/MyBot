# MyBot · Генератор музыки 🎵

Веб-генератор музыки: **сочиняет и синтезирует треки прямо в браузере**, без внешних сервисов и моделей.
Алгоритмическая композиция (гармония, мелодия, бас, арпеджио, барабаны) + синтез через Web Audio API + экспорт в WAV.

Плюс **AI-дирижёр**: описываешь трек словами — языковая модель (Google Gemini) выбирает стиль, лад,
тональность, темп и гармонические прогрессии, а детерминированный движок собирает из этого музыку.
Ключ от Gemini живёт только в серверном процессе и в браузер не попадает.

## Возможности

- **AI-дирижёр**: чат с Gemini — «тёмный синтвейв про ночную поездку, ми миноре, 100 BPM» → готовый трек
- **6 стилей**: Lo-fi, Synthwave, Эмбиент, Техно, Chiptune, Классика
- **5 настроений**: радостное, грустное, мечтательное, тёмное, эпичное — влияют на лад, темп и энергию
- Выбор тональности, темпа (или авто под стиль) и длины трека (~30–120 с)
- **Воспроизводимая генерация**: сид в URL — одна и та же музыка по одной и той же ссылке;
  ссылка с ИИ-рецептом воспроизводит и лад, и прогрессии
- Фортепианный ролл с аккордами и структурой трека, живой спектр-визуализатор
- Циклическое воспроизведение, перемотка, регулятор громкости
- **Экспорт в WAV** (16-bit PCM) — ровно то, что вы слышите

## Запуск

```bash
GEMINI_API_KEY=ваш_ключ python3 server.py     # http://localhost:8000
```

Ключ бесплатный: [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
Без ключа генератор работает как раньше — просто чат-дирижёр отвечает «нужен GEMINI_API_KEY».

Переменные окружения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `GEMINI_API_KEY` | — | ключ Gemini (также `GOOGLE_API_KEY` / `GOOGLE_GENAI_API_KEY`) |
| `GEMINI_MODEL` | `gemini-2.5-flash` | модель; если имя устарело, сервер сам подберёт доступную через ListModels |
| `GEMINI_BASE_URL` | `https://generativelanguage.googleapis.com/v1beta` | другой endpoint / корпоративный прокси |
| `PORT` | `8000` | порт сервера |
| `MYBOT_AI_FAKE` | — | `1` — локальная заглушка вместо Gemini (отладка UI без ключа) |

## Как это работает

```
браузер ──POST /api/chat──▶ server.py ──▶ ai.py ──▶ Gemini (structured output)
   ▲                                             │
   └────── рецепт: стиль, лад, тональность, ◀────┘
           темп, гармония, длительность
   │
   └─▶ composer.js (детерминированно) ─▶ engine.js (Web Audio) ─▶ WAV
```

1. **AI-дирижёр** (`ai.py`): системный промпт описывает возможности движка, ответ запрашивается
   как JSON по схеме (`responseMimeType: application/json` + `responseSchema`) — модель возвращает
   готовый рецепт. Модель держит контекст диалога и знает, что сейчас играет.
2. **Валидация** (`ai.py` + `js/recipe.js`): ключ, лад, стиль, темп и ступени прогрессий
   приводятся к диапазонам, которые движок умеет исполнить. Мусор от модели не доходит до синтеза.
3. **Композитор** (`js/composer.js`) принимает решения ИИ: лад (`scale`), гармонический ритм
   (сколько аккордов в такте) и две прогрессии — основную и контрастную. Остальное (мелодия, бас,
   аранжировка, гуманизация) остаётся детерминированным, поэтому один рецепт + сид = один и тот же трек.
4. **Движок** (`js/engine.js`) озвучивает события осцилляторами и шумом; рендер идёт офлайн
   (`OfflineAudioContext`) одним буфером — экспорт в WAV идентичен прослушиванию.

Если вручную поменять любой селектор в панели параметров, ИИ-режим сбрасывается (в панели появляется
бейдж «ИИ: <лад> · <прогрессии>» — пока он горит, гармония задана дирижёром).

## API

| Метод | Путь | Ответ |
|---|---|---|
| `GET` | `/api/health` | `{"ok":true,"ai":{"provider":"gemini","model":"…","ready":true}}` |
| `POST` | `/api/chat` | `{"messages":[{"role":"user","text":"…"}],"current":{…}}` → `{"ok":true,"reply":"…","recipe":{…},"model":"…"}` |

Ошибки приходят как `{"ok":false,"error":{"code":"…","message":"…"}}` с кодами
`no_key` / `bad_key` / `quota` / `network` / `timeout` / `blocked` / `model_not_found`.

## Тесты

```bash
python3 -m unittest discover -s tests -v   # 32 теста: запрос к Gemini, схема, ошибки, HTTP-эндпоинты
node --test tests/*.test.mjs                # 21 тест: контракт рецепта, композитор, вёрстка
```

Тесты не ходят в сеть: вместо Gemini поднимается локальный мок, который проверяет форму запроса,
JSON-схему, откат при отказе схемы, подбор модели при 404 и маппинг ошибок. Без ключа и без интернета.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Space` | пуск / пауза |
| `G`     | сгенерировать новый трек |
| `Enter` в поле сида | генерация |
| `Enter` в чате | отправить сообщение дирижёру (`Shift+Enter` — перенос строки) |

## Структура

```
index.html        — интерфейс
css/style.css     — оформление
js/theory.js      — музыкальная теория и пресеты
js/composer.js    — алгоритмический композитор (+ решения ИИ)
js/engine.js      — синтез (Web Audio API)
js/wav.js         — кодировщик WAV
js/rng.js         — детерминированный ГПСЧ
js/recipe.js      — контракт рецепта, валидация, параметры URL
js/chat.js        — чат с AI-дирижёром
js/app.js         — UI, плеер, ролл и визуализатор
ai.py             — AI-дирижёр: промпт, схема, Gemini, валидация
server.py         — статический сервер + API-прокси к Gemini
tests/            — тесты Python и JS
```
