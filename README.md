# 🤖 MyBot AI

**Нейросеть, написанная с нуля на чистом NumPy** — без PyTorch, TensorFlow и прочих
фреймворков. Только математика: прямой проход, backpropagation, Adam.

Модель распознаёт **рукописные цифры 0–9**. Есть:
- 🧠 полносвязная сеть со своим autodiff-style backprop (см. `src/nn.py`);
- 📊 CLI-обучение с графиками кривых обучения;
- 🖼️ распознавание картинок из командной строки;
- 🌐 веб-интерфейс: рисуете цифру мышкой — сеть предсказывает в реальном времени;
- 💬 опциональный ИИ-ассистент через любой OpenAI-совместимый API (по ключу).

## Быстрый старт

```bash
pip install -r requirements.txt

# 1. Обучаем нейросеть (датасет цифр встроен в scikit-learn — интернет не нужен)
python -m src.train

# 2. Запускаем веб-интерфейс
python -m src.server          # откроется на http://localhost:8000
```

Рисуйте цифру на холсте — сеть распознаёт её прямо во время рисования.

## Как это устроено

### Нейросеть (`src/nn.py`)
Всё написано вручную на NumPy:

| Компонент | Что делает |
|---|---|
| `Dense` | полносвязный слой `y = xW + b`, инициализация He |
| `ReLU` | нелинейность `max(0, x)` |
| `Dropout` | регуляризация: случайно отключает нейроны при обучении |
| `SoftmaxCrossEntropy` | функция потерь со стабильным softmax |
| `Adam` | оптимизатор (адаптивный градиентный шаг с моментами) |
| `Model` | сборка слоёв, цикл обучения, save/load весов |

Градиенты считаются честным backpropagation — корректность проверяется
численной градиентной проверкой в тестах (`tests/test_nn.py`).

### Данные (`src/data.py`)
- **`digits`** (по умолчанию) — 1797 рукописных цифр 8×8, встроены в
  scikit-learn → обучение работает полностью офлайн.
- **`mnist`** — классический MNIST 28×28 (65 000 картинок). Файлы ищутся в
  `data/`, при отсутствии скачиваются автоматически (нужен интернет):
  ```bash
  python -m src.train --dataset mnist --epochs 20 --hidden 256,128
  ```

## Возможности командной строки

```bash
# Обучение с настройками
python -m src.train --epochs 60 --hidden 256,128 --lr 1e-3

# Распознать картинку с цифрой (png/jpg)
python -m src.predict --image my_digit.png

# Посмотреть пример из датасета и прогноз по нему
python -m src.predict --sample 7

# Прогнать 10 случайных примеров из датасета
python -m src.predict --demo 10

# Тесты (градиентная проверка, XOR, save/load)
python -m tests.test_nn
```

## 💬 ИИ-ассистент (опционально, по API-ключу)

Веб-чат с LLM работает через стандартный `urllib` — никаких лишних библиотек.
Подойдёт любой OpenAI-совместимый API (OpenAI, Groq, OpenRouter, локальный
LM Studio/Ollama):

```bash
export LLM_API_KEY="sk-..."                 # ваш ключ
export LLM_BASE_URL="https://api.openai.com/v1"   # необязательно, это по умолчанию
export LLM_MODEL="gpt-4o-mini"              # необязательно

python -m src.server
```

Без ключа всё остальное (нейросеть, распознавание, веб) работает как обычно —
просто ассистент будет отключён.

## Структура проекта

```
MyBot/
├── src/
│   ├── nn.py          # нейросеть с нуля: слои, backprop, Adam
│   ├── data.py        # загрузка digits/MNIST
│   ├── preprocess.py  # приведение картинок к виду 8×8
│   ├── train.py       # обучение из командной строки
│   ├── predict.py     # предсказания из командной строки
│   ├── server.py      # Flask-вебинтерфейс
│   └── llm.py         # опциональный LLM-ассистент (по ключу)
├── templates/         # HTML
├── static/            # CSS/JS фронтенда
├── tests/             # тесты (градиентная проверка и др.)
├── models/            # обученные веса (.npz) — создаются при обучении
├── outputs/           # графики обучения
└── data/              # кэш датасета / файлы MNIST
```

## Ожидаемое качество

- `digits` (8×8): **~96–98%** точности на валидации после ~40 эпох;
- `mnist` (28×28): **~97–98%** при архитектуре 256,128 и 15–20 эпохах.
