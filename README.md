# MyBot · Генераторы музыки и картинок 🎵🎨

Два генератора в одном месте:

1. **Генератор музыки** (`index.html`) — **сочиняет и синтезирует треки прямо в браузере**, без внешних сервисов.
   Алгоритмическая композиция (гармония, мелодия, бас, арпеджио, барабаны) + синтез через Web Audio API + экспорт в WAV.
2. **ИИ генератор картинок** (`images.html`) — текст → картинка через бесплатную нейросеть Flux (Pollinations.ai),
   без регистрации и API-ключей. Промпт на русском, 12 стилей, 5 размеров, галерея и скачивание.

## Возможности

### 🎵 Музыка

- **6 стилей**: Lo-fi, Synthwave, Эмбиент, Техно, Chiptune, Классика
- **5 настроений**: радостное, грустное, мечтательное, тёмное, эпичное — влияют на лад, темп и энергию
- Выбор тональности, темпа (или авто под стиль) и длины трека (~30–120 с)
- **Воспроизводимая генерация**: сид в URL — одна и та же музыка по одной и той же ссылке
- Фортепианный ролл с аккордами и структурой трека, живой спектр-визуализатор
- Циклическое воспроизведение, перемотка, регулятор громкости
- **Экспорт в WAV** (16-bit PCM) — ровно то, что вы слышите

### 🎨 Картинки

- Промпт на русском + кнопка «Мне повезёт» и чипы-идеи для старта
- **12 стилей**: фотореализм, кинокадр, аниме, киберпанк, фэнтези, sci-fi, акварель, масло, 3D, пиксель-арт, комикс, минимализм
- **2 модели**: Flux (качество) и Turbo (скорость), 5 размеров (квадрат, пейзаж, портрет)
- **1–4 варианта за раз**, воспроизводимость по сиду
- ✨ Улучшение промпта нейросетью, 🔒 приватный режим
- Галерея с историей (сохраняется в браузере), просмотр на весь экран со стрелками
- Скачивание картинок (по одной и всех сразу), ссылка-поделиться с параметрами
- Делитесь ссылкой вида `images.html?prompt=...&style=...&seed=...` — картинка перегенерируется

## Как музыка сочиняется

1. **Теория** (`js/theory.js`): лады, диатонические аккорды, ведение голосов, пресеты стилей и ритм-паттернов.
2. **Композитор** (`js/composer.js`): выбирает гармонический прогресс (например, i–VI–III–VII для синтвейва),
   строит структуру (интро → A → B → аутро), пишет мелодию фразами с переиспользованием мотива,
   раскладывает бас, подложку, арпеджио и ударные с гуманизацией тайминга и свингом.
3. **Движок** (`js/engine.js`): озвучивает события осцилляторами и шумом — FM-электропиано, пады, кислотный бас,
   аналоговые и чиптюн-барабаны, реверберация, дилей и sidechain-«насос»; для Lo-fi добавляет виниловый шум.
4. Всё рендерится офлайн (`OfflineAudioContext`) одним буфром — поэтому экспорт в WAV идентичен прослушиванию.

## Как работают картинки

`js/images.js` собирает URL вида
`https://image.pollinations.ai/prompt/{промпт}?width=…&height=…&seed=…&model=flux&nologo=true`
и загружает результат как обычную картинку. Стиль дописывается к промпту на английском (нейросеть так понимает лучше),
сид гарантирует повторяемость. Для генерации нужен интернет; история хранится в `localStorage`.

## Запуск

```bash
python3 server.py          # http://localhost:8000  (картинки: /images.html)
```

Любой статический сервер тоже подойдёт, например `python3 -m http.server 8000`.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Space` (музыка) | пуск / пауза |
| `G` (музыка) | сгенерировать новый трек |
| `Enter` в поле сида | генерация |
| `Ctrl+Enter` (картинки) | сгенерировать |
| `Esc` / `←` / `→` в просмотре | закрыть / листать картинки |

## Структура

```
index.html        — интерфейс генератора музыки
images.html       — интерфейс ИИ генератора картинок
css/style.css     — общее оформление + навигация
css/images.css    — оформление генератора картинок
js/theory.js      — музыкальная теория и пресеты
js/composer.js    — алгоритмический композитор
js/engine.js      — синтез (Web Audio API)
js/wav.js         — кодировщик WAV
js/app.js         — UI музыки: плеер, ролл и визуализатор
js/images.js      — UI картинок: генерация, галерея, история
server.py         — локальный статический сервер
```
