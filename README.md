# КВАК СРЕДИ НАС 🐸

Браузерная игра в духе Among Us, где все персонажи — лягушки в скафандрах.
Чистый HTML5 canvas + ES-модули: без сборки, без зависимостей, без внешних картинок и звуков.

![скриншот](https://img.shields.io/badge/canvas-2D-4caf50) ![тесты](https://img.shields.io/badge/tests-35%20ok-7dff9e)

## Запуск

```bash
npm start          # = python3 -m http.server 8000 --bind 0.0.0.0
# открыть http://localhost:8000
```

Можно и без npm: `python3 -m http.server 8000` из корня репозитория.

## Правила

Вы — лягушка в скафандре на пруду. Среди вас есть самозванец (или два).

- **Мирная лягушка:** выполняйте задания пруда (5 штук на игрока) и вычисляйте самозванца.
  Победа — если выполнены все задания или все самозванцы выброшены с кочки.
- **Самозванец:** притворяйтесь, что работаете, убивайте поодиночке, прячьтесь в норах
  и мухлюйте с саботажем. Победа — когда самозванцев становится не меньше, чем мирных.

Найденный труп или нажатая большая кувшинка собирают общее собрание: обсуждение, голосование,
выброс («Квакс не был самозванцем…»). Призраки доделывают свои задания и летают сквозь стены.

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` / стрелки | идти |
| мышь / палец | зажать на карте — лягушка пойдёт туда |
| `E` (удерживать) | выполнить задание / починить саботаж |
| `R` | сообщить о трупе |
| `Q` | убить (самозванец) |
| `V` | нырнуть в нору / вылезти (самозванец) |
| `X`, затем `1`/`2` | саботаж: туман или глушение связи (самозванец) |
| `G` | экстренный сбор у большой кувшинки |
| `Esc` | пауза |

## Что внутри

```
index.html            разметка меню, HUD, собраний и финала
styles.css            тема пруда
js/core/config.js     настройки баланса, имена и цвета лягушек
js/core/map.js        карта: комнаты, коридоры, норы, задания, поиск пути (BFS)
js/core/rng.js        детерминированный ГПСЧ (mulberry32)
js/core/rules.js      чистые правила: задания, голоса, победа, решения ботов
js/core/sim.js        симуляция: движение, убийства, саботаж, собрания — без DOM
js/client/render.js   отрисовка мира, туман войны, миникарта
js/client/frog.js     рисование лягушки (живой, мёртвой, призраком, аватаркой)
js/client/ui.js       меню, HUD, голосование, финал
js/client/audio.js    звуки на WebAudio (синтез, без файлов)
js/client/main.js     склейка: ввод → симуляция → кадр
tests/                35 тестов: логика игры + прогон клиента на поддельном браузере
```

Ядро (`js/core`) не знает про DOM и canvas, поэтому всю игровую логику — от связности карты
до подсчёта голосов — проверяют обычные тесты Node. Клиентский код прогоняется через
`tests/fakeBrowser.js`: подделка DOM и canvas-контекста, которая ловит `NaN` в координатах
и обращения к несуществующим свойствам.

## Тесты

```bash
npm test             # = node --test
```

35 проверок: связность карты и доступность всех точек, поиск пути, раздача заданий,
подсчёт голосов и ничьих, все три условия победы, работа ботов за 4 минуты симуляции,
убийство/норы/саботаж/репорт/выброс, призраки, а также полный цикл интерфейса —
от кнопки «В ПРУД!» до экрана финала.
