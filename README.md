# MyBot — локальный ИИ без API и без ошибок 🤖

Простой офлайн-собеседник на Python. Работает **без внешних API, без интернета, без установки сторонних пакетов** — используется только стандартная библиотека Python.

## Возможности

- Общается на русском и немного понимает английский.
- Помнит твоё имя и безопасные факты текущего разговора («я живу в Майкопе», «мне нравится музыка»).
- Поддерживает контекст: понимает «а ты?», «подробнее», «да», «почему?» и продолжает тему.
- Считает математику: `2+2`, `5*8-3`, `(2+3)*4`, `сколько будет 25+17?`.
- Подсказывает время и дату.
- Рассказывает шутки и поддерживает свободную беседу по темам питомцев, дел, развлечений и погоды.
- Поддерживает эмоционально («мне грустно», «я устал»).
- Не падает на пустых, странных и очень длинных сообщениях.
- Показывает несколько встроенных офлайн-карт: мир, Россию, США и Европу — без CDN, API и внешних запросов.

> Важно: это улучшенный автономный диалоговый движок на правилах, а не облачная генеративная нейросеть. Он не отправляет сообщения в интернет и не требует API или сторонних пакетов.

## Запуск в терминале

```bash
python3 bot.py
```

Выход: написать `выход` или `exit`.

## Запуск веб-версии

```bash
python3 server.py
```

Открой в браузере: <http://127.0.0.1:8080>

Можно указать другой порт:

```bash
python3 server.py 9090
```

Веб-интерфейс находится в `index.html` и тоже полностью автономен (без CDN и внешних запросов).

## Тесты (проверка «без ошибок»)

```bash
python3 test_bot.py
```

## Файлы

| Файл           | Назначение                                          |
|----------------|-----------------------------------------------------|
| `bot.py`       | Ядро ИИ: класс `ChatBot` и консольный режим        |
| `server.py`    | Веб-сервер на стандартной библиотеке                |
| `index.html`   | Интерфейс чата                                      |
| `test_bot.py`  | Тесты на отсутствие ошибок и безопасность калькулятора |

## Использование из кода

```python
from bot import ChatBot

bot = ChatBot()
print(bot.reply("Привет!"))
print(bot.reply("меня зовут Никита"))
print(bot.reply("7*8"))
```

## Безопасность

Калькулятор не исполняет произвольный Python-код: поддерживаются только числа и арифметика. Обработка ошибок обёрнута так, что бот никогда не выбрасывает исключение наружу.
