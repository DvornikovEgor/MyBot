# MyBot · Настоящий ИИ + Генератор музыки 🤖🎵

**MyBot** теперь — это **настоящий ИИ, работающий полностью офлайн в браузере** + алгоритмический генератор музыки. Без серверов, без ключей, без отправки данных — всё в твоём браузере.

![offline](https://img.shields.io/badge/offline-%D0%B4%D0%B0-8b5cf6) ![выйти в сеть не нужно](https://img.shields.io/badge/данные-не_уходят-22d3ee)

## Что умеет ИИ 🤖

MyBot AI — гибридный движок: **база знаний + генеративные шаблоны + символьные решатели + цепочки рассуждений**. Работает без интернета.

- **Отвечает и объясняет** — от квантовой физики до рецепта борща, с заголовками, списками и примерами
- **Пишет код** — Python, JavaScript/TypeScript, HTML/CSS, React, Node, парсеры, Telegram-боты (aiogram), API (FastAPI/Express), алгоритмы
- **Решает математику** — выражения, уравнения `2x+5=15`, проценты, задачи по шагам
- **Творит** — истории, сказки, стихи, анекдоты, посты
- **Переводит** RU ↔ EN
- **Помнит контекст** до 32k токенов, хранит историю локально
- **Рассуждает** — модель `MyBot Reason` показывает `<thinking>` цепочку
- **Управляет музыкой** — скажи «сделай тёмный synthwave 90 секунд в ля миноре» и генератор настроится сам
- **Голос** — ввод микрофоном 🎤 и озвучка ответов 🔊
- **Потоковый вывод** — печатает токен за токеном, как ChatGPT

### Модели

| Модель | Скорость | Для чего |
|--------|----------|----------|
| **MyBot Pro** | сбалансированная | Рекомендуется — глубоко и точно |
| **MyBot Flash** | молниеносно | Короткие вопросы |
| **MyBot Reason** | думает дольше | Олимпиадные задачи, рассуждения |

Температура `0` (точно) → `1.5` (креативно). Настройка в боковой панели.

## Генератор музыки 🎵

Остался прежним, но теперь им можно управлять из чата.

- **6 стилей**: Lo-fi, Synthwave, Эмбиент, Техно, Chiptune, Классика
- **5 настроений**: радостное, грустное, мечтательное, тёмное, эпичное
- Тональность, темп (авто) и длина 30–120с
- Сид в URL — одна ссылка = один трек
- Ролл, спектр-визуализатор, loop, перемотка, WAV экспорт

### Как музыка сочиняется

1. **Теория** (`js/theory.js`): лады, аккорды, голосоведение
2. **Композитор** (`js/composer.js`): гармония → структура → мелодия с мотивом → бас/пад/арп/барабаны
3. **Движок** (`js/engine.js`): Web Audio синтез — FM-пиано, пады, кислотный бас, барабаны, реверб/дилей, sidechain, винил
4. Рендер через `OfflineAudioContext` — экспорт WAV идентичен прослушиванию

## Запуск

```bash
python3 server.py          # http://localhost:8000
# ИИ-чат открывается по умолчанию (вкладка ИИ-чат)
# Вкладка Музыка — второй таб
```

Любой статический сервер тоже подойдёт: `python3 -m http.server 8000`

### Подключить облачный LLM (опционально)

ИИ работает офлайн без ключа. Хочешь GPT-4o?

1. В консоли браузера: `localStorage.openai_key = "sk-..."`
2. Или заголовком: `Authorization: Bearer sk-...` на `POST /api/chat`

Сервер проксирует на `https://api.openai.com/v1/chat/completions` (переопредели `OPENAI_BASE_URL`).

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Enter` | отправить в чате |
| `Shift+Enter` | новая строка в чате |
| `Ctrl+1` / `Ctrl+2` | переключить ИИ ↔ Музыка |
| `Space` (в музыке) | пуск/пауза |
| `G` (в музыке) | новый трек |

## Структура

```
index.html        — интерфейс (табы ИИ / Музыка)
css/style.css     — тёмная студийная тема
js/ai-engine.js   — ядро ИИ: KB + генерация + решатели
js/ai-ui.js       — чат UI, стриминг, markdown, голос, память
js/theory.js      — муз. теория и пресеты
js/composer.js    — композитор
js/engine.js      — синтез Web Audio
js/wav.js         — WAV кодер
js/rng.js         — seeded RNG
js/app.js         — табы, плеер, ролл, визуализатор
server.py         — статика + /api/chat прокси
```
